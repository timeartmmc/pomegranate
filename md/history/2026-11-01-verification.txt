POM: COMPLETED IMPLEMENTATION EVIDENCE
2026-11-01

Condensed prior records for execution/cache integration and generation
optimizations. These are dated results, not a new verification run, publication
or application acceptance. Current behavior belongs to README.md, EXECUTION.md,
QUERIES.md and ARCHITECTURE.md; CONTRIBUTING.md owns required checks.

Verification scope

- Execution/cache integration: bun run verify passed with 672 tests on each of
  Node 22.18.0, 24.0.0 and 26.12.1 on the same source snapshot, including strict
  types, type-aware lint, Chromium, example drift/run and a 69-file packed
  install. Minimum consumers used TypeScript 5.7.3, Zod 4.6.6 and Query Core
  5.104.5; source tests used TypeScript 7.0.2. Generated source and emitted
  JavaScript ran without the compiler. Platform declarations and browser/native
  uploads passed.
- Covered scoped inspection isolation, one parse/schema pass, single-use
  evidence, original handles, callback expiry, cancellation mapping,
  parser/context capture, validation budgets, body factories and independent
  declaration consumers. Chromium covered 12 raw/scoped, envelope/body,
  ordinary/cursor/offset combinations plus two mixed-cache cases, with 56
  requests/body reads. Coexisting caches made independent requests/writes;
  operation-wide invalidation refetched each match.
- Later generation optimizations: bun ci and bun run verify passed with 684
  tests, including nine bundle regressions, on Node 26.12.1 and Bun 1.4.3.
  Packed minimum dependencies and compiler-free execution passed. That later
  snapshot was stable during verification; the earlier Node matrix does not
  verify these later changes.

Local measurements

Synthetic execution probe: Node 26.12.1, 10,000 nested items, nine warmed
samples. Median complete calls were 13.0 ms raw, 33.0 ms with an in-executor
parse followed by raw-return parsing, and 24.9 ms scoped with a frozen
inspection copy. These performed one, two and one JSON/schema passes
respectively. Raw parsing falls outside executor budgets; scoped copying falls
inside. Sampled heap growth before collection was approximately 11.2/41.0/37.2
MB, not peak live memory or allocation profiles. Equal-body sharing took about
14.4 ms.

Executable bindings removed 11 handwritten endpoint bindings in their benchmark;
this was not a new integration-wide savings result. Representative generated
output totaled 140,960 unminified TypeScript bytes including notices.

Generation baseline: 90955119d8551b9a00cbd267813cabfa62a92ec3 (0.3.0).
Measurements used Node 26.12.1, Zod 4.6.7, esbuild 0.27.7, minified ES2022
browser ESM and Node default gzip. Terminal alias caching reduced three-run
medians for 10,000 forward aliases: leaf-only 1,059.38 to 18.67 ms; whole-chain
2,045.28 to 41.58 ms. Six complete representative output maps stayed
byte-identical. Contextual constraints/defaults still validate; lookup-count
regressions cover linear resolution. No ordinary-contract timing improvement was
established.
